# Security Policy

## Supported Versions

No released version is currently designated as supported. This policy will be updated when releases are published.

## Reporting a Vulnerability

Please do not publish exploitable vulnerability details in a public issue. Contact the repository maintainer privately through the contact method available on their GitHub profile. Include the affected component, impact, reproduction steps, and any suggested mitigation. Do not send private user files or credentials.

## Safe Use

- Test on a sample folder before using SlothSort on important data.
- Keep backups of important files.
- Do not run the application with elevated privileges unless necessary.
- Treat file names, file contents, and model output as untrusted.
