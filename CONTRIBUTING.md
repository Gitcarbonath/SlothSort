# Contributing to SlothSort

Thanks for considering a contribution!

## Ways to contribute

- Report a reproducible bug or suggest a focused improvement.
- Improve documentation or setup instructions.
- Add tests for file scanning, categorization, duplicate detection, or safe copy behavior.
- Improve accessibility, error messages, or local-model reliability.

## Before opening an issue

Search existing issues first. Include your operating system, Python version, Ollama version/model tag (if relevant), reproduction steps, and expected versus actual behavior. Do not attach private files or sensitive file contents.

## Pull request process

1. Open an issue first for substantial changes so the approach can be discussed.
2. Keep changes focused and explain the reason for the change.
3. Never include personal files, credentials, local paths containing private information, or generated output folders.
4. Add or update tests when behavior changes.
5. Update documentation when setup steps or user-facing behavior changes.
6. Describe what you tested and list anything you could not test.

## Safety expectations

- Prefer copying files over destructive moves or deletion.
- Avoid silently overwriting existing files.
- Treat filenames, file contents, and model output as untrusted input.
- Do not send user files to external services without clear disclosure and consent.
- Do not claim a feature is safe or reliable without testing it.
